# Wallets

Starknet Start does not need connector instances for browser wallets.
`StarknetConfig` wraps `GetStarknetProvider` from `@starknet-io/get-starknet-modal`,
which discovers the wallets injected in the page and exposes them to
[`useConnect`](/docs/hooks/use-connect) and to the
[premade connect UI](/demo/ui).

Three `StarknetConfig` props control which wallets your users see:

- [`recommendedWallets`](#recommended-wallets): wallets to suggest, including
  ones the user has not installed yet.
- [`extraWallets`](#extra-wallets): wallets that can't be discovered from the
  page, such as Cartridge Controller or a wallet injected under a custom key.
- [`store`](#custom-discovery-store): a custom discovery store, to change how
  wallets are discovered.

## Wallet discovery

Injected wallets are discovered automatically. You don't need to configure
anything for wallets that use one of these mechanisms:

| Mechanism                | How the wallet announces itself                                                                                                    |
| :----------------------- | :--------------------------------------------------------------------------------------------------------------------------------- |
| Wallet Standard          | The wallet registers through the `wallet-standard:register-wallet` event and implements the Starknet wallet features.              |
| Legacy `window` objects  | The wallet injects a `StarknetWindowObject` (`id`, `name`, `version`, `icon`, `request`, `on`, `off`) on a `window.starknet*` key. |
| EIP-6963 (MetaMask Snap) | MetaMask announces itself through EIP-6963 and is adapted to Starknet with the Starknet Snap.                                      |

Legacy injected wallets are wrapped in `StarknetInjectedWallet` so every
wallet exposes the same Wallet Standard interface
(`WalletWithStarknetFeatures`). If a wallet is found both ways, the Wallet
Standard registration replaces the legacy one.

:::note
Legacy `window.starknet*` objects are scanned once, when the discovery store is
created. A wallet that injects itself after your app loads, or under a key that
doesn't start with `starknet`, must register through the Wallet Standard or be
passed to [`extraWallets`](#custom-injected-wallets).
:::

## Recommended wallets

`recommendedWallets` takes wallet metadata (`WalletInformation`: `id`, `name`,
`icon` and `downloads` links), not wallet instances. Recommended wallets that
are not installed are listed as `"unavailable"` with their download links.
Installed wallets are matched to their metadata by `id`.

When the prop is omitted, every wallet known to get-starknet is recommended:
Ready Wallet (formerly Argent X), Braavos, MetaMask, OKX Wallet and Keplr. Pass
your own list to change the suggestions, or an empty array to show only
installed wallets.

```tsx twoslash
"use client";
import React from "react";

import { braavos, readyWallet } from "@starknet-io/get-starknet-core/wallets";
import { mainnet } from "@starknetfoundation/starknet-start-chains";
import { publicProvider } from "@starknetfoundation/starknet-start-providers";
import { StarknetConfig } from "@starknetfoundation/starknet-start-react";

function App({ children }: { children: React.ReactNode }) {
  return (
    <StarknetConfig chains={[mainnet]} provider={publicProvider()} recommendedWallets={[readyWallet, braavos]}>
      {children}
    </StarknetConfig>
  );
}
```

`@starknet-io/get-starknet-core/wallets` exports `readyWallet`, `braavos`,
`metaMask`, `okxWallet`, `keplr` and the full `wallets` list. To recommend
another wallet, pass a `WalletInformation` object whose `id` matches the `id`
the wallet injects.

## Extra wallets

`extraWallets` takes Wallet Standard objects (`WalletWithStarknetFeatures[]`)
and lists them alongside the discovered wallets. They are always shown as
available and are returned by `useConnect().connectors`.

Create extra wallets once, outside of render (at module scope or in a
`useMemo`), so they keep the same identity between renders.

### Custom injected wallets

If a wallet injects a `StarknetWindowObject` that discovery doesn't pick up,
wrap it with `StarknetInjectedWallet` and pass it to `extraWallets`.

```tsx twoslash
"use client";
import React from "react";

import { StarknetInjectedWallet } from "@starknet-io/get-starknet-core";
import { mainnet } from "@starknetfoundation/starknet-start-chains";
import { publicProvider } from "@starknetfoundation/starknet-start-providers";
import { StarknetConfig } from "@starknetfoundation/starknet-start-react";

type StarknetWindowObject = ConstructorParameters<typeof StarknetInjectedWallet>[0];

declare global {
  interface Window {
    myWallet?: StarknetWindowObject;
  }
}

// `window` is not defined during server-side rendering.
const injected = typeof window === "undefined" ? undefined : window.myWallet;
const extraWallets = injected ? [new StarknetInjectedWallet(injected)] : [];

export function AppProviders({ children }: { children: React.ReactNode }) {
  return (
    <StarknetConfig chains={[mainnet]} provider={publicProvider()} extraWallets={extraWallets}>
      {children}
    </StarknetConfig>
  );
}
```

Replace `window.myWallet` with the key your wallet injects. If you are building
a wallet, prefer registering it through the Wallet Standard so dapps discover
it without extra configuration.

### Cartridge Controller

Cartridge Controller is not injected in the page. Install both the
`@cartridge/connector` and `@cartridge/controller` packages and pass the Wallet
Standard object returned by `asWalletStandard()` to `extraWallets`.

```bash
pnpm i @cartridge/connector @cartridge/controller
```

```tsx
"use client";
import type React from "react";

import { ControllerConnector } from "@cartridge/connector";
import { mainnet, sepolia } from "@starknetfoundation/starknet-start-chains";
import { cartridgeProvider } from "@starknetfoundation/starknet-start-providers";
import { StarknetConfig } from "@starknetfoundation/starknet-start-react";
import { constants } from "starknet";

const controller = new ControllerConnector({
  chains: [
    {
      rpcUrl: "https://api.cartridge.gg/x/starknet/sepolia",
    },
    {
      rpcUrl: "https://api.cartridge.gg/x/starknet/mainnet",
    },
  ],
  defaultChainId: constants.StarknetChainId.SN_SEPOLIA,
});

export function AppProviders({ children }: { children: React.ReactNode }) {
  return (
    <StarknetConfig
      chains={[sepolia, mainnet]}
      provider={cartridgeProvider()}
      defaultChainId={sepolia.id}
      extraWallets={[controller.asWalletStandard()]}
    >
      {children}
    </StarknetConfig>
  );
}
```

The Controller enables seamless use of Session Keys. Pass session `policies`
to the connector to enable them:

```tsx
import { ControllerConnector } from "@cartridge/connector";
import { SessionPolicies } from "@cartridge/controller";
import { constants } from "starknet";

const policies: SessionPolicies = {
  contracts: {
    "0x3f96056436be253753351fe689110ced7d53f5db3fd98f13df3f19058311b95": {
      name: "Example Contract",
      description: "Example contract interaction",
      methods: [
        {
          name: "Create",
          description: "Create a new instance",
          entrypoint: "create",
        },
      ],
    },
  },
};

const controller = new ControllerConnector({
  chains: [
    {
      rpcUrl: "https://api.cartridge.gg/x/starknet/sepolia",
    },
    {
      rpcUrl: "https://api.cartridge.gg/x/starknet/mainnet",
    },
  ],
  defaultChainId: constants.StarknetChainId.SN_SEPOLIA,
  policies,
});

const extraWallets = [controller.asWalletStandard()];
```

`recommendedWallets` only accepts wallet metadata, so don't pass
`controller.asWalletStandard()` to it. To change where Controller appears in
the premade UI, use the `sortAlgorithm` prop of `WalletConnectModal`.

## Custom discovery store

By default, all `StarknetConfig` instances share one discovery store. Pass your
own `store` to change how wallets are discovered. For example, to stop
offering MetaMask through the Starknet Snap, create a store without EIP-1193
adapters:

```tsx twoslash
"use client";
import React from "react";

import { createStore } from "@starknet-io/get-starknet-core";
import { mainnet } from "@starknetfoundation/starknet-start-chains";
import { publicProvider } from "@starknetfoundation/starknet-start-providers";
import { StarknetConfig } from "@starknetfoundation/starknet-start-react";

// Create the store once: it registers discovery listeners on `window`.
const store = createStore({ eip1193Adapters: [] });

function App({ children }: { children: React.ReactNode }) {
  return (
    <StarknetConfig chains={[mainnet]} provider={publicProvider()} store={store}>
      {children}
    </StarknetConfig>
  );
}
```

You may also want to drop `metaMask` from `recommendedWallets` so it is no
longer suggested.

## Connecting from your UI

Use `WalletConnectModal` from `@starknet-io/get-starknet-ui` for a ready-made
connect button and wallet list; see the [Connect Wallet UI demo](/demo/ui).

To build your own list, `useConnect` returns the discovered and extra wallets
as `connectors`:

```tsx twoslash
"use client";
import React from "react";

import { useConnect } from "@starknetfoundation/starknet-start-react";

function WalletList() {
  const { connectors, connect } = useConnect();

  return (
    <div>
      {connectors.map((connector) => (
        <button key={connector.name} onClick={() => connect({ connector })}>
          <img src={connector.icon} alt="" width={20} height={20} />
          Connect {connector.name}
        </button>
      ))}
    </div>
  );
}
```

`connectors` only contains installed and extra wallets. Recommended wallets
that are not installed are only listed by the premade UI.
