# StarknetConfig

The React Context provider for Starknet.

## Usage

```tsx twoslash
"use client";
import React from "react";

import { mainnet } from "@starknetfoundation/starknet-start-chains";
import { publicProvider } from "@starknetfoundation/starknet-start-providers";
import { StarknetConfig } from "@starknetfoundation/starknet-start-react";

function App() {
  return (
    <StarknetConfig chains={[mainnet]} provider={publicProvider()}>
      {/* your app here */}
    </StarknetConfig>
  );
}
```

## Arguments

### chains

- Type: `Chain[]`

List of supported chains.

### provider

- Type: `ChainProviderFactory`

The JSON-RPC provider you want to use. See [the RPC providers page](/docs/providers) for more information.

### recommendedWallets

- Type: `WalletInformation[] | undefined`

Metadata of wallets to suggest, including wallets the user has not installed yet. Defaults to every wallet known to get-starknet. See [recommended wallets](/docs/wallets#recommended-wallets) for more information.

### extraWallets

- Type: `WalletWithStarknetFeatures[] | undefined`

Additional wallets to show alongside the wallets discovered in the user's browser, such as a wallet injected under a custom key. See [extra wallets](/docs/wallets#extra-wallets) for more information.

### store

- Type: `Store | undefined`

Wallet discovery store created with `createStore` from `@starknet-io/get-starknet-core`. Defaults to a shared store that discovers Wallet Standard, legacy injected and MetaMask Snap wallets. See [custom discovery store](/docs/wallets#custom-discovery-store) for more information.

### paymasterProvider

- Type: `ChainPaymasterFactory | undefined`

Paymaster provider to use for gasless transactions. Defaults to the AVNU paymaster.

### explorer

- Type: `ExplorerFactory`

Explorer factory to use. See [the explorers page](/docs/explorers) for more information.

### queryClient

- Type: `QueryClient`

React Query client to use.

### defaultChainId

- Type: `bigint | undefined`

Default chain to use when no wallet is connected.
If the provided id is not in `chains`, Starknet Start falls back to the first configured chain.
